Este proyecto fue realizado con la intención de modelar un Sistema Bancario, aplicando los conceptos básicos 
de programación orientada a objetos POO; dicho sistema permite modelar distintos clientes (cliente individual y cliente
empresa) y tipos de cuentas bancarias (caja de ahorro, cuenta corriente, cuenta convertibilidad), dentro de las distintas 
operaciones que se pueden realizar encontramos: depósito y extracción de efectivo, cobro de intereses en moneda local,
depósito en cheques, depósito y extracción en dólares, conversión a moneda local y a moneda estadounidense.
Este proyecto se editó en el programa Visual Studio Code y se utilizó la biblioteca de Lombok, además de Java 25 LTS.
Cabe mencionar que el presente proyecto fue modelado en paquetes para organizar mejor los clientes, las cuentas y los testeos.
